1. What is Log / Logging?
-> একটি Service বা Application যখন পরিচালিত হয়, তখন তার ভেতরে প্রতিনিয়ত বিভিন্ন ঘটনা (Event) ঘটে। যেমন: একটি Incoming Request গ্রহণ করা, Database-এ Query করা,
অন্য কোনো API-তে Call করা, অথবা কোনো Function ব্যর্থ হওয়া।

Log হলো এই প্রতিটি ঘটনার একটি স্বয়ংক্রিয়, অপরিবর্তনযোগ্য (Immutable) এবং সময়-নির্ভর (Time-stamped) রেকর্ড।

সহজ ভাষায়, Log হলো একটি Service-এর "Flight Data Recorder" বা "Black Box"। যখন Production পরিবেশে একটি Application পরিচালিত হয়, তখন সরাসরি তার অভ্যন্তরীণ
অবস্থা দেখা যায় না। Log-এর মাধ্যমে নির্দিষ্ট সময়ে Service-এর অভ্যন্তরে কী ঘটছিল, কোন ঘটনা ঘটেছিল এবং কোনো সমস্যা হলে তার কারণ কী ছিল—তা বোঝা যায়।


-> একটি standard Log শুধুমাত্র একটি সাধারণ text message নয়। একে বিশ্লেষণযোগ্য করার জন্য এর ভেতরে কয়েকটি সুনির্দিষ্ট অংশ (Structure) থাকে। নিচে একটি standard Log-এর কোর component গুলো দেওয়া হলো:

-------------------------------------------------------------------------------------------------------------------------------------------------
| Component             | Description
| --------------------- | -----------------------------------------------------------------------------------------------------------------------
| Timestamp             | ঘটনাটি ঠিক কখন ঘটেছে—তারিখ, সময় এবং প্রয়োজনে millisecond precision সহ সময়ের তথ্য।
-------------------------------------------------------------------------------------------------------------------------------------------------
| Log Level             | ঘটনাটির গুরুত্ব বা severity নির্দেশ করে। যেমন: DEBUG, INFO, WARNING, ERROR, CRITICAL।
-------------------------------------------------------------------------------------------------------------------------------------------------
| Message               | কী ঘটনা ঘটেছে তার মূল, human-readable description।
-------------------------------------------------------------------------------------------------------------------------------------------------
| Source / Service Name | কোন Service, Application বা Code Module থেকে log তৈরি হয়েছে তা নির্দেশ করে।
-------------------------------------------------------------------------------------------------------------------------------------------------
| Context / Metadata    | ঘটনাটি বুঝতে প্রয়োজনীয় অতিরিক্ত structured information। যেমন: User ID, IP Address, Correlation ID, Request ID, Order ID ইত্যাদি।
-------------------------------------------------------------------------------------------------------------------------------------------------


-> Json Log Example :
{
  "timestamp": "2026-08-22T13:45:10.123Z",
  "level": "ERROR",
  "service_name": "payment-microservice",
  "correlation_id": "5f9d-4e3b-8a2c-11e9",

  }
}
