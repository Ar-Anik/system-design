# OTel SDK -> OpenTelemetry Software Development Kit
# OTLP -> OpenTelemetry Protocol

- Client / API Layer: Application-এ রিকোয়েস্ট আসার সাথে সাথে OpenTelemetry SDK দ্বারা Root Span ও Trace ID তৈরি হয়।

- In-Process Instrumentation: প্রতিটি মেথড বা ফাংশন কল নতুন Child Span তৈরি করে।

- Cross-Process Propagation: Downstream Service-এ Network Call করার সময় HTTP Header-এ Trace Context Inject করা হয়।

- Data Pipeline (Collector): ব্যাকগ্রাউন্ডে Asynchronous Batching-এর মাধ্যমে Telemetry Data (OTLP Protocol) Collector-এ পাঠানো হয়।

- Storage & UI Layer: Collector থেকে ডাটা Storage-এ সংরক্ষিত হয় এবং UI থেকে Graph বিশ্লেষণ করা যায়।
